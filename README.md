# ENDLESS DRIFT — бесконечная 3D-гонка на HTML5

Браузерная 3D-гонка с дрифтом в духе мобильных дрифт-симуляторов: простая «мультяшная» графика, упор на физику.
Трасса генерируется бесконечно прямо во время езды.

**Играть онлайн:** https://evel7.github.io/game/
**Локально:** просто открой `index.html` в браузере (Chrome, Edge, Firefox). Сервер и установка не нужны.

## Что есть в игре

- **Своя физика машины:** модель шин по формуле Пачейки, круг трения (газ/тормоз «съедают» боковое сцепление),
  перенос веса при разгоне и торможении, пробуксовка ведущих колёс, ручник, кривая момента двигателя,
  автоматическая или ручная коробка, задний ход, прижимная сила, аэродинамическое сопротивление.
  Задний привод легко уходит в занос и держит угол, полный привод сам выравнивается.
  Поперечный перенос веса и «чувствительность шин к нагрузке» (как в симуляторах), «пинок сцеплением»
  (резко отпусти и втопи газ — задок срывается), трекшн-контроль на прямой для честного старта.
- **Лёгкое управление** (по умолчанию): на скорости машина держит поворот и не уходит в занос случайно — дрифт начинается осознанно, ручником или «пинком сцеплением». Помощь при перекладке заноса из стороны в сторону.
- **Помощь в дрифте** (можно выключить): авто-контрруль по углу скольжения, как в аркадных дрифт-играх.
- **20 машин** со своими характеристиками и 6 цветами каждая. Все придуманы — это образы классов машин (в том числе в духе Need for Speed), а не копии реальных моделей:
  - KAZE RS — японское заднеприводное дрифт-купе
  - BULLDOG V8 — американский маслкар
  - VELOCE GT — среднемоторный суперкар
  - TUNDRA R — раллийный хэтчбек с полным приводом
  - RONIN 34 — турбо-купе с полным приводом
  - VANTA GTR — серебристое гоночное купе с синими полосами, «легенда уличных погонь»
  - KITSUNE RX — роторное купе с фарами-«ресницами»
  - TORA MK4 — турбо-купе с большим антикрылом
  - TORO V12 — суперкар-клин с полным приводом
  - STUTT 9 — заднемоторное спорткупе с круглыми фарами
  - SHIRO 86 — лёгкий заднеприводный хэтчбек 80-х с фарами-«мигалками»
  - HAYATE EVO — раллийный седан с турбиной и полным приводом
  - SAKURA S — дрифт-купе нового поколения, самая «дрифтовая» машина
  - STALLION GT — американский фастбэк с V8
  - PIXEL GTI — переднеприводный хот-хэтч
  - ESTATE RS — скоростной универсал с битурбо V8
  - AURORA X — гибридный гиперкар
  - BARS 4x4 — полноприводный внедорожник с люстрой фар
  - BARON M — спортивный бизнес-седан с V8
  - MAMBA ACR — трековый монстр с V10 и антикрылом
- **3 трассы:** каньон «Закат» (пустыня), перевал «Ала-Тоо» (снег, скользко, снегопад), Неон-Сити (ночной город, фонари, неон, фары).
- **3 полигона** — бесконечное открытое поле с рельефом, без трассы: «Асфальт» (площадка с разметкой, конусы, шины), «Пляж» (дюны, пальмы, море), «Снег» (холмы, ёлки, снегопад). Свободная езда, очки за дрифт.
- **Режим управления** (в настройках): «Простой» — мягкий отбойник, машину отводит от ограждений, дрифт мягкий; «Реальный дрифт» — как в симуляторе: сильный ручник, большие углы, без подстраховки.
- **Бесконечная процедурная трасса:** шпильки, шиканы, S-связки, «сжимающиеся» повороты, городские повороты на 90°, плавные переходы кривизны, холмы, поребрики на поворотах, отбойники, декорации, чекпоинты.
- **Длина трассы:** в каждом режиме можно выбрать от 5 до 50 км (в конце — финиш, место среди соперников, рекорд по времени) или бесконечную трассу.
- **Назад ехать нельзя:** в Гонке и Дрифте в 5 м позади самой дальней точки, до которой доехал игрок, стоит стена.
- **Полигоны:** можно выбрать «С препятствиями», «Чистое поле» (без объектов) или «Чистое и ровное» (без объектов и холмов).
- **Онлайн до 8 игроков:** быстрая игра или комната по коду, хост выбирает карту, режим и длину трассы, у всех одна и та же трасса.
- **3 режима:** Гонка (соперники, обгоны, таймер), Дрифт (очки за занос, множитель серии), Свободная езда.
- **Соперники-боты** тормозят перед поворотами по реальной формуле v = √(μ·g·R), объезжают игрока, толкаются.
- **4 камеры:** сзади, сзади дальняя, с капота, кинокамера.
- **Звук полностью синтезируется** (Web Audio): мотор по оборотам, визг шин, ветер, удары, переключения, хлопки, музыка.
- **Детальные машины:** скруглённый кузов с лаком, фары с линзами, фонари, решётки, салон с сиденьями и рулём за прозрачными стёклами, диски со спицами и гайками, тормозные диски и суппорты, зеркала, двери, пороги, номера, диффузоры, антикрылья, каркас безопасности у раллийной машины.
- **Стиль как в мобильных дрифт-играх:** мультяшная заливка и чёрные контуры машин, наклейки спонсоров, полоса на лобовом, буксировочные петли, баннеры вдоль трассы, трибуны со зрителями.
- **Графика:** отражения неба на лакированном кузове, горы и силуэт города на горизонте, облака, свечение (bloom) неона и фар на «Высокой» графике.
- **Высокий FPS:** лимит FPS в настройках (30–240 или без ограничений, по умолчанию 120), счётчик FPS, физика считается 240 раз в секунду.
- Дым из-под колёс, следы шин, крен и клевок кузова, миникарта, спидометр с тахометром, рекорды (сохраняются в браузере), настройки графики.

## Управление

| ПК | Действие |
|---|---|
| `W` / `↑` | Газ |
| `S` / `↓` | Тормоз, задний ход |
| `A` `D` / `←` `→` | Руль |
| `Пробел` | Ручник |
| `C` | Сменить камеру |
| `R` | Вернуться на трассу |
| `E` / `Q` | Передача вверх / вниз (ручная коробка) |
| `M` | Звук вкл/выкл |
| `Esc` / `P` | Пауза |

Геймпад: стик — руль, RT — газ, LT — тормоз, B/RB — ручник, Y — камера, Start — пауза.
На телефоне автоматически появляются сенсорные кнопки.

**Как дрифтовать:** разгонись, поверни и дёрни ручник — задок сорвётся. Держи газ и ловишь угол рулём.
Чем больше угол и скорость, тем больше очков. Длинная серия повышает множитель (до ×5), удар о стену сжигает серию.

## Структура проекта

```
index.html        — страница, меню и HUD
style.css         — оформление
dist/game.js      — собранная игра (один файл, работает без сервера)
server/           — онлайн-сервер (Node.js + WebSocket), render.yaml — деплой на Render
src/
  main.js         — игровой цикл, режимы, камера, HUD, меню
  vehicle.js      — физика автомобиля (не зависит от графики)
  cars.js         — параметры машин
  carmodel.js     — процедурные 3D-модели машин
  track.js        — генератор бесконечной трассы
  maps.js         — карты и декорации
  field.js        — полигоны: бесконечное поле с рельефом
  ai.js           — соперники
  audio.js        — синтез звука и музыки
  input.js        — клавиатура, геймпад, сенсор
  net.js          — онлайн: подключение к серверу, комнаты, позиции других игроков
  fx.js           — небо, дым, следы шин, снег
```

## Онлайн-сервер

Онлайн работает через небольшой сервер на Node.js (папка `server/`). Он держит комнаты и пересылает позиции машин между игроками, физику считает каждый игрок у себя.

**Бесплатно на Render:**
1. Зарегистрируйся на [render.com](https://render.com) через GitHub.
2. **New → Blueprint**, выбери этот репозиторий, нажми **Apply** (настройки уже лежат в `render.yaml`).
3. После деплоя у сервиса будет адрес вида `https://endless-drift-server.onrender.com`.
   Если адрес другой, впиши его в игре: **Онлайн → Адрес сервера** (`wss://…`) или поменяй `DEFAULT_SERVER` в `src/net.js` и пересобери.

Бесплатный сервер Render засыпает после ~15 минут без игроков. Первое подключение после этого занимает до минуты.

**Локально:** `cd server && npm install && npm start` — сервер на `ws://localhost:8080` (игра, открытая с localhost, подключится к нему сама).

## Сборка (если меняешь код в `src/`)

```bash
npm install
npm run build     # пересобирает dist/game.js
npm run dev       # автосборка + локальный сервер
```
